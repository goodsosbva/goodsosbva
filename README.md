## 👨‍💻 About Me

### 저는 궁금한 것을 직접 만들어 보며 이해하는 개발자입니다.

새로운 기술을 접했을 때 사용법만 익히기보다, 왜 필요한지와 내부에서 어떤 흐름으로 동작하는지 알아가는 것을 좋아합니다. 문서로 이해한 내용은 작은 코드로 확인하고, 여러 기술이 연결되는 지점은 실제 프로젝트로 만들어 봅니다.

문제가 생기면 당장 동작하게 만드는 것에서 멈추지 않습니다. 데이터가 어디에서 시작됐는지, 어떤 상태와 조건을 거쳤는지, 설정과 실행 환경이 결과에 어떤 영향을 주었는지를 따라가며 원인을 찾으려고 합니다. 이 과정에서 화면으로 시작한 관심이 자연스럽게 서버, 데이터베이스, 테스트, 배포와 인프라, AI까지 넓어졌습니다.

저에게 폭넓게 공부한다는 것은 많은 기술 이름을 아는 것이 아닙니다. 만들고 싶은 것을 완성하기 위해 필요한 영역을 하나씩 넘어가는 과정에 가깝습니다. 익숙하지 않은 분야라도 직접 실행해 보고, 실패시키고, 다시 고쳐 보면서 제 것으로 만들어 갑니다.

배운 내용과 해결 과정은 가능한 한 코드와 글로 남깁니다. 성공한 결과만 정리하기보다 막혔던 이유, 선택한 방법, 현재 구현의 한계까지 기록하려고 합니다. 기록은 지식을 보여주기 위한 장식이 아니라, 같은 문제를 다시 만났을 때 더 나은 판단을 하기 위한 저만의 개발 자산이라고 생각합니다.

아직 모르는 것이 많다는 사실을 자연스럽게 받아들이지만, 모르는 상태에 오래 머무르지는 않습니다. 필요한 것을 직접 확인하고, 동작하는 결과로 만들며, 그 과정에서 조금씩 더 깊이 이해하는 개발자가 되고자 합니다.


**필요한 기술을 직접 파고들고, 이해한 내용을 제품과 기록으로 남기는 개발자입니다.**
